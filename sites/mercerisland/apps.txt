# Apps installed into the Mercer Island hub image, on top of the built-in apps
# listed in BlackDiamondHub/settings.py.
#
# Each line pins one app wheel from its GitHub release, with its hash
# (pip installs this file with --require-hashes --no-deps), e.g.
#
#   bdh-app-wifi @ https://github.com/blackdiamondlodge/bdh-app-wifi/releases/download/v1.0.0/bdh_app_wifi-1.0.0-py3-none-any.whl \
#       --hash=sha256:<sha256 from the release notes>
#
# An app's third-party dependencies must be in the hub's requirements.txt.
# Installed apps register through the "blackdiamondhub.plugins" entry point.
#
# Same pins as sites/sunpeaks/apps.txt; bump both together. Exception:
# bdh-app-weather is Mercer Island only (Sun Peaks uses its snow report).
